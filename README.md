## 1. Executive Product Overview

The **Expo Floor Operations System** is a dedicated real-time operational layer designed to manage one-of-a-kind high-value diamond inventory during exhibition floor operations. 

It **complements the central enterprise ERP (e.g., SAP Diamond Ledger)**; it does **not** replace it. While the ERP remains the official system of record for accounting, general ledger, and customer accounts, the Expo Floor Ops platform maintains an immutable, cryptographically ordered, time-stamped operational record of:

- **Stone Identity:** One stone, one unique physical GIA/optical identity (e.g., `DIA-2048`).
- **Physical Custody:** Exactly one accountable physical custodian at any given moment.
- **Physical Location:** Verified physical placement (Safe Compartment, Runner Transit, Sales Cabin).
- **Commercial State:** Orthogonal commercial rights (Available, Hold, Memo, Sale Pending ERP, ERP Accepted).
- **Operational Event Chain:** Every movement has an actor, timestamp, and verifiable outcome.
- **ERP Outbox Bridge:** Floor transactions are captured in an asynchronous transactional outbox with idempotency keys; sales are not officially complete until ERP confirms acceptance.

## 2. Core Product Principles Enforced by System Logic

1. **One stone, one unique identity:** Each diamond cassette is uniquely identified; duplicate IDs are mathematically prevented.
2. **One active physical custodian at a time:** Physical custody is never split or ambiguous. Custody transitions only occur via mutual acknowledgement.
3. **Physical custody and commercial state are orthogonal dimensions:** A diamond can be physically *In Cabin* while commercially *On Hold*, or physically *In Safe* after a sale. They are never conflated into a single status field.
4. **Every action produces an audit record:** All movements, scans, and commercial transactions generate an immutable event with actor, timestamp, location, and outcome.
5. **Stale or unconfirmed data is never presented as current:** All screens surface real-time state, live possession timers, and explicit sync statuses.
6. **A floor sale is not officially posted until ERP confirms acceptance:** Firm buyer commitments create a `Sale Pending ERP` state in the transactional outbox; only central ERP confirmation marks the transaction complete.
7. **A return is not complete until the stockroom scans safe receipt:** A runner collecting a diamond from a cabin shifts status to `Return Transit`. Safe return custody closes exclusively when the Stock Controller verifies the cassette at the safe room gate.

## 4. Local Setup & Execution

### Prerequisites
- Node.js version 18+ or 20+ (tested on Node v22)
- npm or pnpm

### Quick Start
```bash
# Clone or navigate to the directory
cd "d:\antigravity\simster presentation"

# Install dependencies (if not already installed)

# Start the development server
npm run dev
```

Open your browser at `http://localhost:5173`.

## 5. Deployment Instructions (Vercel)

This application is fully production-ready and configured for instant zero-configuration deployment to [Vercel](https://vercel.com):

1. **Push to GitHub / GitLab / Bitbucket:**
   ```bash
   git init
   git add .
   git commit -m "feat: complete SimStar Expo Floor Operations platform"
   git remote add origin <your-repo-url>
   git push -u origin main
   ```
2. **Import Project into Vercel:**
   - Log into Vercel dashboard and click **"Add New Project"**.
   - Select your repository.
   - Framework Preset: **Vite**
   - Root Directory: `./`
   - Build Command: `npm run build`
   - Output Directory: `dist`
3. **Deploy:**
   - Click **Deploy**. Vercel will build and deploy the app with the included `vercel.json` SPA rewrite rule.

## 7. Known Limitations & Prototype Scope

- **Simulated ERP Gateway:** Network calls to SAP ERP / central diamond ledgers are simulated locally with realistic delays, idempotency keys, and sequence numbers.
- **Simulated Laser Scanners:** Barcode scanning is simulated via high-fidelity interactive modal triggers (Correct vs Mismatch) rather than requiring physical USB HID laser hardware.
- **Demo Data Disclaimer:** All diamonds, certificates, serial numbers, client names, and employees are fictional.
